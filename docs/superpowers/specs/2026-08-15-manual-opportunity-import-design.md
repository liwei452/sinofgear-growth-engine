# 人工导入公开客户线索设计

日期：2026-08-15

## 目标

让工厂老板把自己有权使用的公开网页线索保存为真实的客户机会，结束“客户机会只有 Demo 数据”的状态。系统只保存用户提交的事实和证据，不主动抓取网页、不登录平台、不联系任何人。

## 用户体验

“客户机会”页在机会队列上方提供次要入口“导入公开线索”。点击后展开一张简短表单：

- 公司名称；
- 国家或地区；
- 行业；
- 来源名称；
- 公开 HTTPS 链接；
- 原始证据摘要。

页面明确提示：“系统不会访问该网页，也不会自动联系客户；请只提交你有权使用的公开信息。”提交成功后关闭表单、刷新机会队列并选中新机会。每条机会继续单独显示 `Demo / Fake` 或“许可/用户提供来源”，页面标题不再把所有机会统一标成 Demo。

## 后端边界

新增 `POST /api/v1/growth/opportunity-imports/manual-url`，继续使用现有组织隔离和活动管理权限。请求仅接受上述字段，不接受账号密码、Cookie、个人邮箱或任意内部对象参数。

服务在单个数据库事务中：

1. 规范化空白并验证长度；
2. 要求 HTTPS，拒绝带用户名/密码、localhost、`.local` 及私有、回环、链路本地或保留 IP；
3. 根据规范化后的来源链接和证据正文计算 SHA-256；
4. 同一组织中相同证据哈希幂等返回已有记录；
5. 按用户明确提供的公司名称复用同组织的完全同名公司，否则创建非 Demo 目标公司；
6. 创建 `MANUAL_URL` 需求信号，保存原始证据、来源、哈希和保守的版本化评分。

服务不发起 DNS 查询或 HTTP 请求，因此来源地址只作为证据定位信息保存。API 返回新建或已存在的目标公司与需求信号，以及 `created` 状态。

## 评分与真实性

人工导入没有经过许可数据接口或 AI 事实抽取，不能仅凭用户粘贴内容进入高意向层级。`manual-opportunity-v1` 使用固定、透明的保守评分：

- ICP 匹配 15；
- 意向强度 15；
- 信号时效 12；
- 角色相关 3；
- 证据覆盖 10；
- 风险扣分 5；
- 总分 50。

待确认事项固定包含“公司身份仍需人工核实”和“采购范围与时间仍需人工确认”。因此导入后显示“继续观察”。后续只有新增可验证证据并通过现有证据门槛，才允许提升为“优先跟进”。

## 错误处理

- 字段错误返回对应中文提示，不写入部分数据；
- 重复提交返回 200 和原记录，不创建重复公司或信号；
- 新建成功返回 201；
- 前端提交失败时保留表单内容，并显示可重试提示；
- 工作区刷新失败不伪造成功队列，已保存记录仍可在下次刷新恢复。

## 测试

后端覆盖组织隔离、HTTPS/主机校验、哈希幂等、事务原子性、保守评分和非 Demo 标签。前端覆盖展开/取消、提交载荷、成功选中新机会、字段错误和失败保留。浏览器验收覆盖导入、刷新、查看证据与“继续观察”，所有测试仅使用 `example.invalid`，不访问外网。

## 明确不做

- 不抓取或解析来源网页；
- 不做 RSS、搜索引擎、LinkedIn 抓取或自动补全；
- 不导入个人邮箱、电话、Cookie 或登录态；
- 不自动生成或发送私信、邮件；
- 不接入真实付费数据源、OAuth、生产部署或独立站代码。

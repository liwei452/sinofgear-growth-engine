# SinoFGear Growth Cockpit UI Design Package

Version: 2026-08-16  
Target stack: Vue 3 + Vue Router + TanStack Query  
Purpose: handoff to WorkBuddy or another UI implementation platform

## Start here

This package defines the approved blue-and-white UI redesign for the SinoFGear AI growth system. It is a presentation and interaction redesign, not a business-logic rewrite.

Read in this order:

1. `01-product-brief.md`
2. `02-design-system.md`
3. `03-page-blueprints.md`
4. `04-components-and-states.md`
5. `05-code-and-data-boundaries.md`
6. `06-acceptance-checklist.md`
7. `WORKBUDDY-PROMPT.md`

Machine-readable design values are in `design-tokens.json`. The approved visual reference is `reference-dashboard.png`.

## Required outcome

Create a calm, credible, professional industrial B2B growth cockpit with five primary destinations:

- Today / 今天
- Promotion / 推广
- Customer Opportunities / 客户机会
- Results / 效果
- My Company / 我的公司

The owner should understand the next useful action within five seconds. The UI must never invent customers, scores, charts, performance, readiness, or AI results.
